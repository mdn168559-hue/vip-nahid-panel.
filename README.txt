VIP NAHID PANEL

Files:
- index.html: complete single-page interface.

Features:
- Phone + password registration and login
- Separate moderator login
- Moderator password setup on first open and password change
- Moderator can set member accounts Active / Inactive
- Member list, login records, posts, profile and dashboard
- Gold/black responsive layout

IMPORTANT LIMITATION:
This is a browser-only single-device implementation. Data is stored in that browser's localStorage and the signed-in session in sessionStorage. It does not provide secure multi-user hosting, cross-device records, real server-side authorization, OTP verification, or reliable password security. A production deployment requires a backend/database and server-enforced moderator roles. Do not use this as a real authentication system or store real users' sensitive information.
